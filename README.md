# falcon
NSF VINES Track 2 FALCON project website (GitHub Pages).

Plain static HTML — no build step.

- `index.html` — home: architecture figure, project overview, applications, research thrusts
- `team.html` — participating organizations and personnel
- `publications.html` — publication list (empty for now; template in an HTML comment)
- `assets/css/style.css` — shared styles (NYU violet theme)
- `assets/logos/` — organization logos

To publish: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
